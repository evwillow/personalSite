For UC Berkeley's Econ 143 (Econometrics: Advanced Methods), Evan ran a quantile-regression study of whether pre-breakout volume contraction predicts upper-tail returns on Qullamaggie-style momentum setups. He locked the hypothesis in a timestamped commit before the estimator ran, then reported the null as it came, with a bootstrap interval and a shuffled-label placebo. Code and write-up: github.com/evwillow/econ143-project.
